# Apple Stock Analysis (1981-2023)

## Project Overview

This project analyzes Apple stock prices from 1981 to 2023 using:

- Pandas
- NumPy
- SciPy
- Matplotlib

## Key Findings

- Dataset contains 10,608 observations.
- Average closing price: $16.70.
- Maximum closing price: $182.01.
- Daily returns are not normally distributed.
- Significant difference exists between average closing prices in 2022 and 2023.
- Weak negative correlation (-0.215) between stock price and trading volume.

## Tools Used

- Pandas for data manipulation
- NumPy for numerical analysis
- SciPy for hypothesis testing
- Matplotlib for visualization
